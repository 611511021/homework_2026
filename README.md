# 待辦清單程式（TodoList）
 
一個用 Python 寫的命令列待辦清單程式，可新增、列出、編輯、完成／取消完成及刪除待辦事項，資料會自動存檔，重新啟動後仍可讀回。
 
## 專題題目
 
**待辦清單程式（TodoList）**
 
## 目標
 
1. 實作命令列待辦清單的基本功能：新增、列出、編輯、完成／取消完成、刪除。
2. 每次操作後自動存檔，重新啟動程式後可讀回原本的清單。
3. 妥善處理異常輸入（空白內容、無效編號、無效選項、存檔不存在或損毀），不讓程式崩潰，也不錯誤修改資料。
4. 具備可攜性：不依賴個人電腦的絕對路徑或特殊環境設定，存檔位置相對於程式所在目錄。

### 操作方式
 
啟動後會顯示選單，輸入數字選擇功能：
 
```
=== 待辦清單 ===
1. 列出待辦
2. 新增待辦
3. 編輯待辦
4. 完成／取消完成
5. 刪除待辦
0. 離開
請選擇：
```
 
- 編輯、完成、刪除時，依畫面列出的編號輸入要操作的項目。
- 列表中 `[x]` 表示已完成，`[ ]` 表示未完成。
- 輸入 `0` 離開；按 `Ctrl+C` 也可安全結束。
## 測試方法
 
測試依據 [驗收規格草案](docs/BMI_ACCEPTANCE.md) 第 2、3 節進行。測試前請先備份或刪除既有的 `todos.json`，從空清單開始。
 
### 一、正常操作案例（8 筆）
 
| # | 操作 | 預期結果 |
|---:|---|---|
| 1 | 選 `1` 列出 | 顯示「目前沒有任何待辦。」 |
| 2 | 選 `2` 新增「買牛奶」 | 清單 1 筆：`[ ] 買牛奶` |
| 3 | 選 `2` 新增「寫作業」 | 清單 2 筆，順序為買牛奶、寫作業 |
| 4 | 選 `4`，輸入 `1` | `[x] 買牛奶`，第 2 筆不變 |
| 5 | 再選 `4`，輸入 `1` | `[ ] 買牛奶`（取消完成） |
| 6 | 選 `3`，輸入 `2`，改為「寫待辦清單作業」 | 第 2 筆內容更新，狀態不變 |
| 7 | 選 `5`，輸入 `1` | 只剩「寫待辦清單作業」，編號變為 1 |
| 8 | 選 `0` 離開，重新執行後選 `1` | 讀回第 7 步後的清單 |
 
### 二、異常輸入案例（10 筆）
 
| # | 測試輸入 | 預期處理 |
|---:|---|---|
| 1 | 新增時內容空白 | 顯示「內容不可空白。」，未新增 |
| 2 | 新增時內容只有空格 | 視為空白並拒絕 |
| 3 | 編輯時新內容空白 | 拒絕，保留原內容 |
| 4 | 編號輸入 `abc` | 顯示「編號無效。」，資料不變 |
| 5 | 編號輸入 `0` 或負數 | 顯示「編號無效。」，資料不變 |
| 6 | 編號大於項目數量 | 顯示「編號無效。」，資料不變 |
| 7 | 清單為空時編輯、完成或刪除 | 顯示「目前沒有任何待辦。」 |
| 8 | 選單輸入不存在的選項（如 `7`） | 顯示「選項無效，請重新輸入。」並重新顯示選單 |
| 9 | `todos.json` 不存在（首次執行） | 以空清單開始 |
| 10 | `todos.json` 內容損毀 | 顯示「讀取存檔失敗，將以空清單開始。」 |
 
判定標準：程式不崩潰、資料不被錯誤修改，且使用者能看出輸入未被接受。
 
### 三、快速自動測試（macOS / Linux）
 
用管線輸入模擬操作，可快速執行正常案例第 2～7 步：
 
```bash
printf '2\n買牛奶\n2\n寫作業\n4\n1\n4\n1\n3\n2\n寫待辦清單作業\n5\n1\n0\n' | python3 TodoList.py
printf '1\n0\n' | python3 TodoList.py   # 重新啟動並列出，應只剩「寫待辦清單作業」
```
 
測試存檔損毀的情況（會覆蓋存檔，請先備份）：
 
```bash
echo 'broken' > todos.json
printf '1\n0\n' | python3 TodoList.py   # 應顯示「讀取存檔失敗，將以空清單開始。」
```
